# 토픽 맵 — 출제기준(2023) 원문 코드 ↔ 초안(A1) 코드 ↔ 합격코치(cce) topicId

`app/data/topics.js`(`window.PL_TOPICS`)의 원본 근거 문서. 코드는 `sources/official/출제기준_2023.txt`(표 원문, hwp 재추출로 전문 확인) 순서를 그대로 따르고, 예상 문항수(`exp_q`)·단답 예상(`exp_short`)은 `work/A_도메인설계_결과.md` A1.1~A1.5의 값을 이름 대응으로 옮긴 것이다. A1의 세부항목 코드(예: `1.1.1 입법취지`)는 초안 기준이라 원문과 번호 체계가 다르므로, 이 문서의 "원문 코드"만 앱·문항 데이터의 `topic` 필드에 쓴다.

## 구조 확인

- 원문 「맞춤형화장품 조제관리사 출제기준(2023)」은 **4.7 충진 및 포장(제품에 맞는 충진 방법 및 포장 방법)에서 끝난다.** hwp를 다시 직접 파싱(`olefile` PARA_TEXT, 109개 문단)해 `.txt` 변환본과 대조했고, 4.8은 존재하지 않는다. A1 표에 있는 "4.8 재고관리(3문항, 3+0)"는 A1 작성 세션이 만든 초안 항목이며, 이 세션에서는 그 값을 원문 4.6의 마지막 세부내용(4.6.5 맞춤형화장품판매업 준수사항에 맞는 혼합·소분 활동)에 흡수했다(재고·발주 관리도 넓게 보면 판매업 준수사항의 운영 실무이기 때문). 근거: `sources/official/출제기준_2023.txt` 전체, 아래 "구조 확인 로그" 참고.
- 원문 과목·주요항목·세부내용 개수: ① 화장품법의 이해(주요항목 2·세부내용 8), ② 화장품 제조 및 품질관리(주요항목 5·세부내용 13), ③ 유통 화장품 안전관리(주요항목 5·세부내용 30), ④ 맞춤형화장품의 이해(주요항목 7·세부내용 19). 합계 주요항목 19 + 세부내용 70 = `PL_TOPICS` 89개 항목.
- 세부내용이 1개뿐인 주요항목(2.5 위해사례 판단 및 보고, 4.3 관능평가 방법과 절차, 4.5 제품 안내)도 브리프 지시대로 `x.y.1` 세부코드를 만들었다.

## 배분 원리 요약

- 과목별 mcq/short 합계(①7+3 ②20+5 ③25+0 ④28+12)는 CLAUDE.md·2024 문항유형표의 공식 값이며 조정 대상이 아니다.
- 1·2과목은 A1이 세부항목 단위로 값을 주었으므로 원문 세부내용과 이름을 대조해 1:1 또는 여러 개를 병합해 옮겼다(예: 원문 1.1이 5개 세부내용인데 A1 초안은 6개 — "입법취지"를 "화장품의 정의 및 유형"에 병합).
- 3·4과목은 A1이 **주요항목 단위 합계만** 주었다(세부항목별 분해 없음). 이 세션에서 각 세부내용에 값을 배분할 때는 A1의 TESTABLE POINT(TP) 서술에서 어느 세부내용이 더 자주 언급·강조되는지(H/M 표시, 조문 존재 여부)를 참고해 정수로 나눴다. 이 배분은 실제 회차별 출제 데이터가 아니라 **추정**이며, 각 항목에 `note`로 표시했다.
- 정수 배분 특성상 여러 세부내용에 0이 배정된 경우가 있다(예: 3.4.4 보관 중 출고기준, 3.5.2 입고 포장재 관리기준). 이는 "출제 안 됨"이 아니라 "A1 근거로는 우선순위가 낮다"는 뜻이며, 콘텐츠 생성 시 여전히 최소 1~2문항은 만들어 커버리지를 확보하는 것을 권장한다.
- `exp_q` 과목 합계는 정확히 10/25/25/40, `exp_short` 합계는 정확히 3/5/0/12로 맞췄다(테스트 (5)로 검증).
