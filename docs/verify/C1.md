## 이번 배치에서 드러난 생성 규칙의 약한 곳

1. **과목별 배점 슬롯이 생성 규칙에 반영되지 않았다.** Task 7 공통 규칙의 "18점은 배치당 최대 1개"만 보고 과목①에 18점을 만들면 `blueprint.js` 과목① 슬롯(18점 0)과 충돌해 모의고사에 배치될 수 없다. 생성 프롬프트에 "배치의 subject에 해당하는 blueprint 슬롯을 먼저 확인" 문구가 필요하다.
2. **가이드를 규범 주체로 쓰는 지문**("가이드가 정한 …")이 나왔다. 가이드가 스스로 인용한 법령(여기서는 시행령 제16조)을 지문 근거로 쓰는 것이 옳다.
3. 조문 인용 보기를 축약하면 조문 대조가 어려워진다(제30조제1항제6호). 보기 문장은 조문 문구를 그대로 옮기는 것이 안전하다.
