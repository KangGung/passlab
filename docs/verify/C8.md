## 3. 검증자 판정(저자 §7 확인 요청 5건)

1. **Q-C8-08 ㉠ 허용표기 범위** → 현행 유지. 가이드 p.273이 "접촉 피부염"과 "자극접촉 피부염"을 모두 쓰므로 세 표기 다 근거 있음. `strict_term:true`도 유지(동의어표가 화학명 전용이라 실질 영향 0).
2. **Q-C8-02 `strict_term:true`와 '기호'·'분석' 단독 인정** → 단독 표기는 **불인정**으로 변경. '-형'이 용어의 일부이고 '기호'는 symbol과 혼동된다. 오답 처리가 아니라 4단계 자기 판정으로 넘어가므로 학습 손해 없음.
3. **Q-C8-09 "지체 없이" vs 15일** → **둘 다 참**. 다만 문두가 기준을 밝히지 않아 모호했으므로 문두·해설·trap을 수정해 두 기한을 모두 적었다(FIX).
4. **Q-C8-11 `law_effective_date:"2025-12-16"`** → 유지. 소스가 2026-09-05 수집 현행본이며 시험일 기준 시행 중. (2026년 별표 4 개정 여부는 웹 확인 불가 — 잔여 위험으로만 기록.)
5. **Q-C8-12 `law_effective_date:"2026-09-11"`** → 유지. 개인정보 보호법 제23조 현행본과 개정본을 나란히 대조해 제1항·제1호 문언이 동일함을 재확인했다(개정은 제2항 "유출등" 정의뿐).
