# PASS LAB 운영 가이드 (지훈님용)

이 문서는 개발자가 아니어도 읽을 수 있게 썼습니다. 어려운 말이 나오면 옆에 괄호로 풀어 놓았습니다.

지금 상태(2026-09-05 밤 기준): 문항 96개 · 암기카드 50장 · 전부 검증(사실관계 확인) 완료. 시험까지 D-14(14일 남음).

## 1. 여는 법

**Mac(이 컴퓨터)에서**
- `조제관리사시험/app` 폴더 안의 `index.html` 파일을 더블클릭하면 바로 앱이 열립니다. 인터넷 연결도, 로그인도 필요 없습니다.

**아이폰에서**
- 아직 아이폰용 주소가 없습니다. 인터넷에 앱을 올리는 것(**GitHub Pages 배포**라고 부릅니다 — 무료로 파일을 인터넷 주소 하나로 공개하는 방법)은 지훈님이 "올려도 된다"고 확인해 준 다음에 진행합니다.
- 승인해 주시면 그다음 세션에서 주소를 만들어 드리고, 아이폰 사파리(Safari)로 그 주소를 열어 **[공유] → [홈 화면에 추가]**하는 방법을 안내해 드리겠습니다. 그러면 앱처럼 아이콘을 눌러 바로 쓸 수 있습니다.

## 2. 매일 끝날 때: 백업 내보내기

이 앱은 서버가 없어서, 푼 문제와 점수 기록이 전부 **이 컴퓨터(또는 이 아이폰) 안에만** 저장됩니다. 컴퓨터를 바꾸거나 인터넷 사용 기록을 지우면 기록이 사라질 수 있습니다. 그래서 **공부를 마칠 때마다 백업**을 눌러 주세요.

1. **설정** 탭의 **[백업 내보내기]** 버튼을 누릅니다. (백업이 2일 넘게 없으면 홈 위쪽 배너에도 나옵니다.)
2. `passlab-진행-YYYY-MM-DD-기기.json` 같은 이름의 파일이 다운로드됩니다. (예: `passlab-진행-2026-09-05-mac.json`)
3. 이 파일을 **iCloud Drive**의 `passlab_backups` 같은 폴더를 하나 만들어 그 안에 옮겨 두는 것을 추천합니다. iCloud Drive에 넣어 두면 Mac과 아이폰 양쪽에서 같은 파일을 볼 수 있습니다.
4. 백업을 2일 넘게 안 하면 화면 위에 경고 배너가 뜹니다. 그때는 꼭 눌러 주세요.

## 3. 기기를 옮길 때 (가져오기)

Mac에서 풀던 것을 아이폰에서 이어서 풀고 싶을 때:

1. Mac에서 최신 백업 파일을 내보냅니다(위 2번).
2. 그 파일을 아이폰으로 옮깁니다(예: 에어드랍, iCloud Drive, 카카오톡 나에게 보내기 등 편한 방법).
3. 아이폰 앱의 설정 화면에서 **[가져오기]**를 누르고 그 파일을 선택합니다.
4. "지금까지 아이폰에 있던 기록을 지우고 이 백업으로 덮어씁니다. 계속할까요?" 같은 확인 창이 **두 번** 뜹니다. 두 번 다 확인해야 실제로 덮어씁니다(실수로 지우는 것을 막기 위한 안전장치입니다).

주의: 지금 버전은 "덮어쓰기"만 됩니다. 두 기기에서 각각 문제를 풀고 나중에 하나로 합치는 기능(병합)은 아직 없습니다. 그래서 되도록 한 번에 한 기기로만 공부하고, 옮길 때만 가져오기를 쓰는 것을 권합니다.

## 4. 문항(문제)을 더 추가하고 싶을 때

지금 96문항이 있고, 시험 범위(출제기준)에서 아직 다루지 않은 부분도 있습니다. 문항을 더 만들고 싶으면 이렇게 클로드에게 요청하면 됩니다.

1. 새 클로드 대화를 열고 이렇게 말합니다: "`03_빌드_프롬프트팩_v2.md`의 ④ 프롬프트로 세부항목 {코드와 이름}을 문항 {개수}개 만들어줘." (세부항목 코드는 `docs/S0_report.md`의 C 섹션이나 `app/data/topics.js`에서 찾을 수 있습니다. 예: "3.2.5 작업자 위생관리")
2. 문항이 만들어지면, **반드시 다른 대화(세션)에서** ⑤ 검증 프롬프트로 한 번 더 사실 확인을 시킵니다(같은 사람이 만들고 같은 사람이 검사하면 실수를 놓치기 쉬워서, 문제 출제와 검증은 항상 나누어 합니다).
3. 검증이 끝나면 `app/data/manifest.js`(앱이 읽어들이는 파일 목록)에 새 파일 이름을 등록해 달라고 요청합니다.
4. 마지막으로 "데이터 점검 해줘"라고 하면 `node scripts/check-data.cjs` 명령으로 오류가 없는지 확인해 줍니다. 앱 화면 안에도 **[데이터 점검]** 버튼이 있어서, 앱을 열고 그 버튼을 눌러도 같은 확인을 볼 수 있습니다.

이 네 단계(생성 → 검증 → 등록 → 점검)를 항상 순서대로 지켜 주세요. 순서를 건너뛰면 틀린 문제가 그대로 시험 준비에 섞일 수 있습니다.

## 6. 문제(오류·에러)가 생겼을 때

앱이 이상하게 동작하거나 화면이 깨지면:

1. **당황해서 [초기화](Reset) 버튼부터 누르지 마세요.** Reset을 누르면 지금까지 기록이 전부 지워집니다(자동으로 백업을 한 번 만들긴 하지만, 되도록 안 누르는 게 안전합니다).
2. 화면을 그대로 스크린샷으로 찍어 둡니다.
3. 설정 화면에서 **[데이터 점검]**을 눌러 그 결과 화면도 스크린샷으로 찍습니다.
4. 가장 최근 백업 파일(2번 항목 참고)이 어디 있는지 확인해 둡니다.
5. 이 세 가지(스크린샷 + 데이터 점검 결과 + 백업 파일)를 클로드에게 보여주면서 어떤 화면에서 무슨 버튼을 눌렀을 때 이상해졌는지 설명해 주세요. 그러면 재현하고 고치기가 훨씬 쉬워집니다.

## 8. 모의고사 보는 법 (2026-09-08 추가)

**모의고사**는 실제 시험처럼 시간을 재고 한 번에 쭉 푸는 화면입니다. 학습 화면과 다르게 **푸는 도중에는 정답·해설이 안 나오고**, 다 풀고 제출한 뒤에 한꺼번에 채점 결과를 봅니다.

### 1) 프리셋(모의고사 종류) 고르기

하단 탭 **◷ 모의**를 누르면 세 가지 중 하나를 고를 수 있습니다.

- **실전 모의고사** — 100문항 · 120분. 진짜 시험과 똑같은 구성(네 과목 전부). 합격/불합격(600점 이상 + 과목별 40% 이상)까지 판정해 줍니다.
- **하프 모의고사(①②③)** — 50문항 · 60분. **오늘 저녁 권장**이라고 표시됩니다. ④(맞춤형화장품의 이해) 과목이 빠져서 전체 합격 판정은 하지 않고, 과목별 과락(40% 미달) 여부만 보여줍니다. 시간이 부족할 때 먼저 이걸로 감을 잡는 용도입니다.
- **3과목 미니** — 25문항 · 30분. ③(유통 화장품 안전관리) 한 과목만. 아주 짧게 감만 잡고 싶을 때 씁니다.

각 카드에는 문항 수·시간·배점이 적혀 있고, 문항이 부족해서 원래 계획과 다르게 짜였으면 "환산 점수" 같은 안내 문구가 뜹니다(예: 배점이 조금 다른 문항으로 대체됐다는 뜻 — 걱정하지 않으셔도 됩니다, 점수는 1000점 만점으로 다시 계산해 줍니다).

### 2) 시작 전 확인

[시작]을 누르면 바로 시작되지 않고, "**시작하면 타이머가 돕니다. 해설은 제출한 뒤에만 나옵니다. 중간에 나가도 시간은 계속 흐릅니다.**"라는 확인 문구가 뜹니다. [네, 시작합니다]를 눌러야 진짜로 시작됩니다.

### 3) 문항을 풀 때 화면 쓰는 법

- 위쪽에 **남은 시간**, **답함 n/N**(지금까지 답을 고른 문항 수), **⚑ n**(검토 표시한 문항 수), **[제출]** 버튼이 항상 고정되어 있습니다.
- **번호판** 버튼을 누르면 1번부터 끝 번호까지 작은 버튼판이 펼쳐집니다. 버튼 색으로 상태를 알 수 있습니다 — 답을 고른 문항은 진하게, **⚑ 검토** 표시한 문항은 테두리가 다르게, 지금 보고 있는 문항은 파란 테두리로 표시됩니다. 아무 번호나 눌러서 바로 그 문항으로 건너뛸 수 있습니다.
- 문항마다 **[⚑ 검토]** 버튼이 있습니다 — "이건 나중에 다시 볼래" 표시입니다. 채점에는 영향이 없고, 번호판에서 표시만 남습니다.
- **[찍음]** 버튼 — 답은 골랐지만 확신이 없을 때 누릅니다. 나중에 결과 화면에서 "찍어서 맞힌 문항"을 따로 빼고 계산한 점수(더 실력에 가까운 점수)를 보여줄 때 씁니다.
- **[이전] / [다음]**으로 문항을 옮겨 다닙니다. 답·검토·찍음 표시는 누르는 즉시 자동 저장됩니다.

### 4) 앱을 닫아도 시간은 실제로 계속 갑니다

모의고사 중에 실수로 앱을 닫거나 다른 일을 하다 와도, 남은 시간은 **달력의 실제 시각 기준으로 계속 줄어듭니다**(멈춰 있지 않습니다). 다시 열면 홈 화면 위쪽에 **[이어하기]** 버튼이 남은 시간과 함께 나타나므로 눌러서 이어서 풀면 됩니다. 시간이 다 되면 자동으로 제출됩니다.

### 5) 제출과 미답 확인

**[제출]**을 누르면 아직 답을 안 고른 문항이 있는지 확인해 줍니다. 안 고른 문항(**미답**)이 있으면 "몇 문항이 비어 있고 0점으로 처리된다"고 미리 알려줍니다. [네, 제출합니다]를 눌러야 실제로 채점되고, [더 풀기]를 누르면 다시 돌아가서 마저 풀 수 있습니다.

### 6) 결과 화면 읽는 법

- **환산 점수** — 실제로 푼 문항의 배점을 1000점 만점으로 다시 계산한 점수입니다(하프·미니처럼 과목 일부만 봤거나, 문항이 부족해 배점이 조금 다른 문항으로 대체된 경우에 씁니다).
- **찍음 제외 점수** — "찍어서 맞힌 문항"의 배점을 빼고 다시 계산한 점수입니다. 환산 점수보다 이 점수가 **실력에 더 가깝습니다**(운으로 맞은 것을 뺐기 때문).
- **과락선** — 과목별로 정해진 최저 통과선(40%)입니다. 과목별 막대그래프에 빨간 선으로 표시되고, 막대가 그 선을 못 넘으면 "과락"이라고 표시됩니다. 실전 모의고사에서는 총점 600점 이상이면서 네 과목 모두 과락이 아니어야 **PASS**입니다.
- **취약 세부항목**(하프·미니는 "약한 세부항목") — 정답률이 낮은 순서로 최대 8개까지 보여줍니다. 가장 약한 항목 아래에는 "오답노트 만기 재시험 + 연결 암기카드부터 보세요" 같은 처방 문구가 같이 나옵니다.
- **문항별 해설** 버튼을 누르면 각 문항의 정답·해설·연결된 암기카드를 하나씩 다시 볼 수 있습니다. **오답노트 보기** 버튼으로 틀린 문항만 모아 볼 수도 있습니다.
- **미답 문항**은 따로 목록으로 보여주고 전부 0점 처리됩니다.

### 7) 홈 화면의 예상 점수 · SAFE / BORDERLINE / AT RISK

홈 화면 위쪽에 항상 **예상 점수**(지금까지의 학습 기록 + 모의고사 결과를 섞어 계산한 1000점 만점 예상치)와 그 옆에 색깔 표시가 있습니다.

- **SAFE**(초록) — 모의고사를 1번 이상 봤고, 예상 점수와 최악의 경우(하한)까지 합격선을 넉넉히 넘고, 네 과목 모두 40% 이상일 때.
- **AT RISK**(빨강) — 예상 점수가 600점보다 많이 부족하거나, 하한이 540점 미만이거나, 어느 한 과목이라도 40% 미만일 때. 지금 서둘러야 한다는 뜻입니다.
- **BORDERLINE**(주황) — 그 사이. 조금 더 준비하면 안전권에 들어갈 수 있는 상태입니다.

과목별 칩(①②③④)에는 "미측정 / 안전 / 주의 / 위험" 같은 말로 그 과목이 얼마나 준비됐는지도 같이 보여줍니다.

### 8) QUICK 10 / QUICK 20이 뭔가요

홈 화면 "오늘 할 일" 카드에 있는 짧은 연습 버튼입니다. 시간을 정해 놓고 앉아서 모의고사를 볼 여유가 없을 때, **10문항 또는 20문항만 짧게** 풉니다. 문항은 임의로 고르는 게 아니라 앱이 "지금 가장 필요한 문항"(약한 것 절반 · 복습할 때가 된 오답 30% · 새 문항 20%)을 골라 주고, 모의고사와 달리 **문항마다 바로 해설이 나옵니다**. 시험 전날처럼 시간이 없을 때 가장 자주 쓰게 될 기능입니다.

## 9. 암기카드 쓰는 법 (2026-09-08 추가)

**암기카드**는 법령 숫자·용어 정의·순서처럼 "이해"가 아니라 "그냥 외워야 하는 것"을 짧은 카드 형태로 반복해서 보여주는 기능입니다. 문제를 푸는 것과는 별도로, 하루에 정해진 만큼만 넘겨 보면 됩니다.

### 1) 카드 탭 열기

하단 탭 **▤ 카드**를 누르면 카드 홈이 열립니다. 맨 위에 숫자 세 개가 보입니다.

- **오늘 만기** — 오늘 다시 봐야 할 카드 수입니다(예전에 본 카드 중 "이제 다시 볼 때가 된" 카드).
- **새 카드** — 아직 한 번도 본 적 없는 카드 수입니다.
- **내 메모리 노트** — 문제를 풀다가 **틀렸거나 찍어서 맞힌 문제**에 연결된 카드가 자동으로 여기 담깁니다. 따로 챙기지 않아도, 틀린 문제와 관련된 암기가 자동으로 여기 모이는 것입니다.

**[오늘 카드 시작 (n장)]**을 누르면 카드 세션이 시작됩니다. n은 오늘 볼 수 있는 최대 장수(하루 공부 시간에서 정해진 몫)입니다.

### 2) 카드 넘기기 — 뒤집기와 세 가지 버튼

카드 세션에서는 먼저 카드 **앞면**(질문·단어)만 보입니다. 카드를 누르거나 **[뒤집기]** 버튼을 누르면 **뒷면**(답 + 그림 + 외우는 방법 + 근거)이 나오고, 그때부터 아래 세 버튼을 누를 수 있습니다.

- **[모름]** — 오늘 세션이 끝나기 전에 **한 번 더** 나오고, 그다음엔 **내일** 다시 나옵니다.
- **[애매]** — **내일** 다시 나옵니다.
- **[알아요]** — 카드가 담긴 "박스"가 한 칸 올라가고, 다시 나오는 날짜가 점점 늘어납니다: 박스가 올라갈수록 **1일 → 2일 → 4일 → 7일** 뒤에 다시 나오는 식입니다. 박스가 높을수록 "잘 외웠다"는 뜻이라 뜸하게 나옵니다.

### 3) 박스 분포 읽기

카드 홈에는 막대그래프로 박스 ①~⑤ 별 카드 수가 보입니다. **①이 많을수록 아직 잘 못 외운 카드가 많다**는 뜻이고, **⑤에 가까울수록 잘 외운 카드**입니다. 시험이 다가올수록 이 그래프가 오른쪽(⑤ 방향)으로 쌓이는 게 목표입니다.

### 4) 시험이 가까워지면 (D-3부터)

시험 3일 전(D-3)부터는 카드 홈 맨 위에 빨간 안내가 뜹니다: **"매일 박스 ①~③은 전부 보고, 박스 ④⑤는 시험 전날(D-1)에 한 번만 봅니다."** 다 외운 카드까지 매일 볼 필요는 없고, 아직 안 외운 것 위주로 마무리하라는 뜻입니다.

### 5) 암기노트 한 장 내보내기

카드 홈의 **[암기노트 한 장 내보내기]**를 누르면, "내 메모리 노트"에 담긴 카드와 아직 잘 못 외운 카드(박스 ①~③), 그리고 틀린 문제의 한 줄 암기를 과목별로 모아 **하나의 글 파일**로 만들어 줍니다. 시험 전날 프린트하거나 마지막으로 훑어보기 좋은 요약본입니다. 옆의 **[복사]**를 누르면 같은 내용을 클립보드로 복사해서 다른 곳(메모 앱 등)에 붙여넣을 수도 있습니다.

### 6) 프리셋 3개 — 오늘 뭘 볼지 골라주는 버튼

**학습** 화면 맨 위에 버튼 3개가 있습니다. 문제와 카드를 한 세트로 골라서 이어서 볼 수 있게 해 줍니다.

- **WEAKNESS ATTACK (약점 공격)** — 지금 가장 약한 세부항목 위주로 문제를 풀고, 끝나면 그 항목의 암기카드로 이어집니다.
- **LAW & NUMBERS (법령·숫자)** — 숫자·기한·한도처럼 외워야 하는 문제와 카드만 모아서 봅니다.
- **TODAY'S REVIEW (오늘 복습)** — 오늘 다시 봐야 할 오답과 오늘 만기 카드를 한 번에 몰아서 봅니다.

각 버튼을 누르면 먼저 문제를 풀고, 다 풀면 "이어서 암기카드 보기" 버튼이 뜹니다.

### 7) 백업 가져오기 — "병합"과 "덮어쓰기"의 차이

설정 화면의 **[가져오기]**에는 이제 방식을 두 가지 중에서 고를 수 있습니다.

- **덮어쓰기** — 지금 기기의 기록을 전부 지우고 백업 파일 내용으로 통째로 바꿉니다. 한 기기만 쓸 때 옮기는 용도입니다.
- **병합** — 지금 기기의 기록과 백업 파일의 기록을 **둘 다 살려서 하나로 합칩니다**. 예를 들어 아이폰에서 오늘 카드를 몇 장 보고, Mac에서 만든 예전 백업을 병합으로 가져오면, 두 기기에서 본 기록이 전부 남습니다. **기기 두 대를 번갈아 쓸 때는 병합을 골라 주세요.** 병합을 누르면 "기록 n건 추가·카드 m장 갱신" 같은 미리보기가 먼저 뜨고, 확인을 눌러야 실제로 합쳐집니다.
