### Task 1: core.js 확장 — 모의고사 구성·채점, 예상 점수·READINESS, 적응형 출제, 주간 리포트 (TDD)

파일: `app/core.js`(기존 함수 유지, 아래 추가), `tests/core.test.cjs`(추가). 모든 상수는 `CLAUDE.md` "학습 알고리즘 상수" 그대로.

**모의고사 프리셋(상수 `MOCK_PRESETS`)**
```js
{ full:  { name:"실전 모의고사", minutes:120, subjects:[1,2,3,4], scale:1 },            // 블루프린트 슬롯 그대로 100문항
  half:  { name:"하프 모의고사(①②③)", minutes:60, subjects:[1,2,3], counts:{1:10,2:20,3:20} },  // 슬롯을 과목별 count에 비례 축소(반올림, 합 맞춤)
  mini3: { name:"3과목 미니", minutes:30, subjects:[3], counts:{3:25} } }
```
- `buildMock(presetKey, questions, blueprint, opts, rng)` → `{ qids, order, slots_filled, slots_missing:[{subject,type,points,need,got}], partial, total_points, minutes, warnings }`.
  - 슬롯 = 블루프린트 `subjects[].slots`(full) 또는 count에 비례 축소한 슬롯(half·mini3; 유형 비율은 과목의 mcq/short 비율 유지, 배점 비율은 슬롯 비율 유지, 반올림 후 합계를 count에 맞춤).
  - 채움 규칙: 슬롯(과목·유형·배점)마다 `verified:true` 문항 중 **미출제(attempts 없음) 우선 → 가장 오래전 출제** 순, 같은 세부항목 최대 3문항. 슬롯이 비면 같은 과목·유형의 **다른 배점** 문항으로 대체(8↔12 먼저, 18은 마지막). 그래도 비면 비운 채 `slots_missing`에 기록, `partial:true`.
  - `order`: 선다형 먼저(과목 1→4 순, 과목 안은 무작위) 다음 단답형(과목 1→4). 번호 = 배열 인덱스+1. `opts.exclude`(직전 모의 qids)는 가능하면 피한다.
- `gradeMock(mock, answers, questions, blueprint)` → `{ raw, max_included, scaled, adj, pass, fail_subjects, partial, by_subject:[{id,name,raw,max,scaled,pass_points,pass,ratio}], mcq:{n,correct,points}, short:{n,correct,points,self_marked}, guessed_correct:[qid], guessed_points, by_topic:[{id,name,n,correct,pct}], avg_sec, slowest:[{qid,sec}], unanswered:[qid] }`.
  - `answers = { qid: { given, conf, sec, flag, self_marked } }`. 채점은 `gradeMcq`/`gradeShort`(단답 self_marked는 정답 인정하되 `short.self_marked` 카운트).
  - `raw` = 정답 문항 points 합. `max_included` = 포함 문항 points 합. `scaled` = partial이면 round(raw/max_included×1000), 아니면 raw. 과목별도 같은 방식(scaled 과목 만점 = 블루프린트 과목 points). `pass` = `judgePass`(scaled 과목 점수). `adj` = scaled − round(0.8 × 찍어서 맞힌 문항 배점 합 × (partial ? 1000/max_included : 1)).
  - `by_topic` 낮은 순, `slowest` 상위 5.
- `mockRecord(mock, grade, sid, dateStr)` → `pl.v1.mocks` 항목 `{ sid, date, preset, raw, max_included, scaled, adj, pass, fail_subjects, partial, subject:[4개 scaled], mcq, short, guessedCorrect:n, avgSec, slowest, n }`.

**예상 점수·READINESS**
- `expectedScore(mocks, topics, questions, attemptsByQid, blueprint, todayStr)` → `{ E, band, low, high, basis:"mastery|mixed|mock", n_mocks, by_subject:[{id, E, max, ratio}], mastery_based, mock_based, note }`.
  - 숙달 기반: 과목별 `subjectMastery` m(0~100, 미측정 20) → 선다 p = 0.20+0.80×m/100, 단답 p = 0.85×m/100 → `Σ 슬롯(count×points×p)`. 모의 기반: 최근 모의 `adj`(full은 그대로, half·mini3은 포함 과목만 반영하고 나머지 과목은 숙달 기반으로 채움)의 최근 가중(1회 1.0 / 2회 0.7·0.3 / 3회+ 0.6·0.3·0.1). 혼합: 0회 E=숙달 band 120 note "초기 추정 · 신뢰 낮음" / 1회 0.5·0.5 band 90 / 2회+ 0.7모의+0.3숙달 band 60. `low=E−band, high=E+band`.
- `readiness(exp, blueprint)` → `{ label:"SAFE|BORDERLINE|AT RISK", reasons:[…] }`: SAFE = n_mocks≥1 AND E≥700 AND low≥620 AND 전 과목 ratio≥0.5 / AT RISK = E<600 OR low<540 OR 어느 과목 ratio<0.4 / 그 외 BORDERLINE(n_mocks=0이면 최대 BORDERLINE). `subjectBadge(ratio, n)`: n<8 "미측정", ≥0.55 안전, 0.45~0.55 주의, <0.45 위험.

**적응형 출제**
- `buildAdaptiveSet(n, questions, topics, attemptsByQid, mistakes, todayStr, rng)` → `{ qids, mix:{W,R,N} }`. 비중 W 50/R 30/N 20(n=10 → 5/3/2, n=20 → 10/6/4). R = `dueMistakes`(같은 vg 형제 우선). W = 토픽 숙달<60 또는 문항 mastery<50(R·숙달 제외), P = 3(1−mastery/100) + 2[3일 내 오답] + 1.5·min(연속 오답,3)/3 + 1[마지막 conf≤1] + 1[평균 sec > 목표×1.5; 목표 선다 72·단답 90] + 1.5·중요도(H1/M0.5/L0) + 1·(토픽 exp_q/최대 exp_q); P 상위 2×필요 수에서 무작위. N = 미출제 문항을 토픽 exp_q 가중 추첨. 부족분은 R→W→N→가장 오래전 순. 같은 문항 중복 없음, 한 과목 60% 상한(가능할 때).

**주간 리포트 데이터**
- `weeklyReport(attempts, mocks, topics, questions, todayStr)` → `{ days:7, n_attempts, correct_pct, by_subject:[{id,pct,n}], weak_topics:[{id,name,pct,n}](하위 8), why_dist:{unknown,confused,slip,misread,guess}, conf_dist:{2,1,0}, mocks:[{date,preset,scaled,adj,pass}] }` (⑨-B 템플릿 채움용).

**TDD 최소 테스트**: buildMock full로 96문항 은행에서 partial·slots_missing 정확(①10 ②23 ③24 ④39 은행 → 최소 96 포함, missing 4 기록) / half 슬롯 축소 합계 50·유형 비율 / 미출제 우선 결정성(seed) / gradeMock 만점·0점·partial 환산·찍음 보정·과락 경계(과목 39.9%↔40%) / expectedScore 0·1·2회 band 120·90·60·혼합 가중 / readiness 3분기 + 0회 상한 / buildAdaptiveSet 비중 5/3/2, 만기 문항 포함, 중복 없음 / weeklyReport 집계.

   [제출] → 미답 n개 확인창("미답 n문항은 0점 처리") → `gradeMock` → attempts에 `mode:"mock", sid` 기록(문항별 sec 포함) → 오답·찍음정답은 `applyAttemptToMistake` → `mockRecord`를 `pl.v1.mocks`에 push → 세션 삭제 → 결과 화면.
