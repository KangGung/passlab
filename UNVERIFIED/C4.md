## 검증 세션에 남기는 확인 요청

1. **Q-C4-06 `strict_term:true` + `blanks`** — ㉡의 허용표기를 "벌크 제품 / 벌크제품 / 벌크 제품(bulk product) / bulk product"로 두었다. `normalizeShort`가 공백을 지우므로 띄어쓰기 차이는 흡수되지만, **"벌크"만 쓴 답은 오답**(near_miss에 넣어 둠)이다. 이 엄격도가 적절한지 확인 요망. 실제 채점 테스트: `["반제품","벌크제품"]`→정답, `["반제품","내용물"]`→오답 확인함.
2. **Q-C4-10 `grade:"set"`** — `core.js`의 `splitSet()`은 `answer_text` 배열의 **모든 원소를 하나의 토큰 집합으로 합친다**. 따라서 set 문항의 `answer_text`는 반드시 원소 1개(쉼표로 구분한 정답 전체)여야 하며, 대체 표기를 원소로 추가하면 토큰 수가 늘어 정답이 불가능해진다. 이 문항은 원소 1개로 두었다. 채점 테스트: 순서 바꾼 정답→정답, "제조관리기록서"로 바꾼 답→오답 확인함.
3. **Q-C4-07 source 이중 귀속** — 정답 보기 ③은 「화장품법」 제2조제1호 원문("인체에 대한 작용이 경미한 것", 단서로 의약품 제외)과 가이드 인쇄 p.106 문장이 모두 근거다. `source.law`와 `source.guide`를 함께 채웠다.
4. **가이드 4판의 기준 법령일** — §2.2.1·§2.2.2 참고문헌은 「화장품법」 2025-08-01 시행본과 「사용할 때의 주의사항 규정」 2024-09-24 시행본을 인용한다. C4 문항 중 2026 개정으로 값이 달라지는 논점(점자·수어영상 표시, 화장품의 날 등)은 없으므로 개정 영향은 없다고 판단했다. CGMP를 인용한 문항 2건(Q-C4-06·09·10)은 `law_effective_date:"2024-08-22"`(고시 제2024-46호)로 적었다.

### 출제자 확인 요청에 대한 판정
1. **Q-C4-06 `strict_term:true`("벌크" 단독 불인정) — 유지.** CGMP는 이 개념을 항상 "벌크 제품"/"벌크제품"으로만 쓰고(제2조제7·17·18·21호, 제13조, 제17조, 제20조) "벌크" 단독 표기가 없다. 가이드의 "벌크" 단독 용례는 `s4.txt`:1807 "내용물(벌크)"·1758·2557 "벌크용기"뿐으로 4과목 맞춤형 문맥의 괄호 병기·복합어이며 정의된 용어가 아니다. 지문이 제18호 정의 문언을 그대로 인용하므로 답은 정의된 용어명이어야 한다 → 허용표기 추가 없음. 다만 "벌크"는 3자라 근사(편집거리) 대상도 아니어서 **stage 4 자기 판정 경로**로 떨어지므로 조용한 0점이 아니다.
2. **Q-C4-10 `grade:"set"` — 출제자 판단 정확.** `app/core.js`:261~266이 `answer_text` 전 원소를 한 집합으로 합치므로 set 문항의 `answer_text`는 원소 1개여야 한다. 실채점기로 어순 4종 임의 배열·쉼표/빗금/줄바꿈 구분 정답, 항목 추가·누락·"기록서" 치환 오답 확인. 공백만으로 구분한 답은 엔진 공통 규격상 오답(지문이 "쉼표로 구분"을 명시해 문항 결함 아님).
3. **향수 부향률 수치 — 두 파일에 % 단정 없음 확인.** 부향률 관련 문장은 모두 원문 문구뿐이며 A-1 처리가 옳다.
4. **Q-C4-07 source 이중 귀속 — 적절.** 정답 ③은 「화장품법」 제2조제1호 본문·단서(법령 원문)와 가이드 인쇄 p.106 문장 양쪽에 근거가 있어 `source.law`·`source.guide` 동시 기재가 맞다.
5. **B 표(4~10번) 제외 판단 — 전부 타당.** 특히 4번(공정 온도·rpm의 "예:"·"정도" 값)과 10번(참고자료 예시 서식의 pH·비중·ppm·cfu·97 %)을 `limit_number` 정답으로 쓰지 않은 것은 "소스에 없는 숫자 단정 금지" 규칙에 부합한다.
