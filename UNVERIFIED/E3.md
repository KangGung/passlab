# UNVERIFIED — 배치 E3 (3.1.1~3.1.5 작업장 위생관리)

작성 2026-09-09 / 출제 에이전트(E3, 줄기 B). 문항으로 만들려 했으나 **원문 근거가 충돌하거나 불충분해 채점용 문항에서 뺀 논점**을 적는다.
(문항 파일: `app/data/q_e3_31.js` 13문항, 카드 파일: `app/data/c_e3_31.js` 3장)

열어 본 원문: `sources/law/CGMP.txt`(제7~10조·제15조제5항) · `sources/official/guide4/s2.txt`(3.1.1, 인쇄 164) · `sources/official/guide4/s3.txt`(3.1.2~3.1.5, 인쇄 165~187) · `sources/official/CGMP해설서_제4개정_2024-12-30.txt`(제9조·제10조 해설 및 보완사례 9-1·9-2·10-1, 필터·공기조화 절)

**근거를 못 찾아 문항에서 뺀 숫자: 0건.** 아래는 근거가 서로 다르게 인쇄되어 있거나, 중복을 피하려고 뺀 논점이다.

## 1. Pre Filter의 전처리 대상 — 같은 표 안에서 표기가 다름
- 가이드 4판 p.169 필터 표의 '규격' 칸: Pre Filter는 "Medium Filter 전처리용".
- 같은 표 '특징' 칸: "HEPA, EDIUM 등의 전처리용"(원문 오탈자 포함).
- 조치: "Pre Filter는 무엇의 전처리용인가"를 정·오 판단의 근거로 쓰지 않았다. Q-E3-05는 **필터 입자·압력 손실·제거 효율 숫자만** 채점 근거로 썼고, 오답 ⑤는 'HEPA에 Pre Filter의 재사용·부직포 특성을 붙인 것'으로 만들었다.

## 2. 소독용 알코올 농도 — 가이드 표와 해설서 본문이 다르다
- 가이드 4판 p.187 화학적 소독제 표: 아이소프로필알코올 60 ~ 70 %(15분), 에탄올 60 ~ 95 %(15분).
- CGMP 해설서 제4개정 제9조 해설(설비·도구 소독 서술): "보통 70∼80% 에탄올, 70∼80% 이소프로필 알코올 또는 열수(뜨거운 정제수)등으로 설비, 도구 소독".
- 조치: 두 값을 한 문항에 섞지 않았다. Q-E3-12는 **가이드 표(3.1.5 작업소 소독제)** 값만 썼고, 해설서의 70~80 %는 문항에 쓰지 않았다. (해설서 값은 설비·도구 소독 절차 서술이므로 3.3.x 배치에서 다루는 것이 맞다.)
- Q-E3-08 (나)의 "70 % 에탄올"은 농도를 채점하지 않고, 해설서 **보완사례 9-2**(소독에 사용하는 70 % 에탄올에 사용기한을 부여할 것)의 문구를 그대로 상황으로 옮긴 것이다.

## 3. 청정도 등급표·화학적 소독제 장단점·화학적 세척제 pH 구간
- 이미 출제됨(Q-B4-02 청정도 등급, Q-B4-03 소독제 장단점, Q-B4-06 세척제 pH 구간·연마제/금속이온봉쇄제). E3에서는 같은 표를 **다른 축**으로만 물었다: 차압·온습도(Q-E3-03), 필터 규격(Q-E3-05), 소독제 농도·시간(Q-E3-12), 살균제/금속이온봉쇄제·표백성분(Q-E3-10).
- 인접 중복 주의로 검증자에게 넘기는 두 쌍: **Q-E3-12 ↔ Q-B4-03**(같은 표, 숫자 vs 장단점), **Q-E3-10 ↔ Q-B4-06**(같은 참고자료, 살균제 vs 연마제).

## 4. '분리·구획·구분' 정의 (가이드 4판 p.173)
- CGMP 작업소 맥락의 3용어 정의로 8점 definition을 만들 수 있었으나, **Q-C9-09(4.6.4)에 이미 '구분 vs 구획' 단답 빈칸 문항**이 있어 논점이 겹친다고 보고 제외했다. 대신 3.1.2는 차압·시설기준·필터로 채웠다.
- 재검토 필요: '분리'(별개의 건물 또는 별개의 장소)는 아직 어느 문항에도 없다 — 다음 보강 시 3.1.2 8점으로 쓸 수 있다.

## 5. 표면균 시료 채취 3법의 장단점 (가이드 4판 p.181 참고자료 4)
- 면봉 시험법·콘택트 플레이트법·린스 정량법의 장단점 표는 출제 가치가 높지만, **Q-C6-09(3.3.2 설비 세척 후 위생 상태 판정 = 육안·닦아내기·린스액)**와 붙어 있어 이번 배치에서는 카드(C-E3-02)에 목록으로만 남기고 문항은 만들지 않았다.

## 6. 공기 조화 방식 표(AHU·FFU·ACCU) — 해설서에만 있음
- 해설서 p.35~36에 AHU/FFU/ACCU와 전열교환기 표가 있으나 가이드 3.1.2에는 '센트럴 방식'과 '팬 코일 + 에어컨 방식' 두 가지만 인쇄되어 있다.
- 조치: 가이드에 없는 약어(AHU·FFU·ACCU)는 시험 범위 표기로 확신할 수 없어 문항·카드에 쓰지 않았다. 카드 C-E3-01에는 가이드 기준 두 방식만 적었다.

## 검증 REMOVE (S2-V 2026-09-09)

**해당 없음.** 검증 세션(`S2-V`, 출제와 다른 에이전트)이 13문항·3카드를 원문과 1:1 대조한 결과 REMOVE(삭제·이관) 대상은 0건이다. 정답 오류 0건, 복수정답·무정답 0건, 미시행 조문 혼입 0건.

검증에서 내린 판정 4건(출제 리포트가 남긴 확인 요청):

1. **Q-E3-12 ↔ Q-B4-03 (인접 쌍) = 유지.** 같은 표(가이드 인쇄 186~187)를 쓰지만 채점 대상이 다르다 — Q-B4-03은 '장점·단점' 칸(4급 암모늄의 세정 작용·부식성 없음·포자 무효·경수 불활성화), Q-E3-12는 '종류(사용 농도, 시간)' 칸의 숫자 짝짓기. 오답 보기도 겹치지 않는다. 다만 **두 문항의 정답 보기가 모두 '4급 암모늄' 행**이라 한 회차에 같이 나오면 유형 이름만으로 답을 찍을 여지가 있다 → 정답 행 교체는 검증 범위를 넘으므로 `docs/verify/E3.md`에 후속 권고로만 적었다.
2. **Q-E3-10 ↔ Q-B4-06 (인접 쌍) = 유지.** 채점 대상이 다르다 — Q-B4-06의 정답은 '중성 세척제 pH 5.5 ~ 8.5', Q-E3-10의 정답은 '소듐트리포스페이트 등 = 금속이온봉쇄제(살균제 아님)'. 금속이온봉쇄제가 한쪽에서는 오답 보기(연마제와 혼동), 다른 쪽에서는 정답 논점(살균제와 혼동)으로 쓰여 같은 개념을 다른 각도로 다시 묻는 변형에 해당한다.
3. **Q-E3-08 (다) '배수로 월 1회 락스 소독' = 유지(적절 쪽 근거로만).** 참고자료 1(인쇄 178)의 제조실 청소 방법은 규범이 아니라 예시지만, 이 문항은 예시에 **부합하는지**를 물어 '적절'로 판정하는 데만 썼다. 예시는 부합 확인(적절)에는 쓸 수 있고 위반 판정(부적절)의 근거로는 쓸 수 없다 — 이 문항은 앞쪽만 쓴다. 검증에서 stem의 판단 기준에 '해설서(제4개정)'를 추가하고(가·나·마의 근거가 보완사례 9-1·9-2·10-1) 오답 해설 ③을 '예시에 그대로 부합'으로 정정했다.
4. **에탄올 농도 충돌 = 문항 유지, 근거 출처 표기 보강.** Q-E3-12의 채점 대상(4급 암모늄 200 ppm/제조사 추천농도)은 두 자료가 충돌하지 않으므로 규칙(양쪽이 일치하는 것만 채점하거나 출처를 명시)에 어긋나지 않는다. 다만 해설·trap에 실린 알코올 농도가 가이드 표 값임을 분명히 하도록 trap에 "가이드 3.1.5 표 = 에탄올 60~95 %·IPA 60~70 % / CGMP 해설서 설비·도구 소독 서술 = 70∼80 %"를 병기했다(해설서 원문 위치: `CGMP해설서_제4개정_2024-12-30.txt`:1395~1396).
5. **(추가) Pre Filter 표기 엇갈림 = 카드에 병기.** 가이드 인쇄 169 필터 표는 같은 칸 안에서 재사용 횟수를 '규격 칸 3~4회 / 특징 칸 2~3회', 전처리 대상을 '규격 칸 Medium Filter / 특징 칸 HEPA, EDIUM 등'으로 다르게 인쇄한다. 두 값 어느 쪽도 채점 문항의 정·오 판단에 쓰이지 않았음을 확인했고(Q-E3-05는 필터 이름과 입자·압력 손실·제거 효율만 채점), 카드 C-E3-01에는 두 표기를 병기해 한쪽만 사실로 굳지 않게 고쳤다.
