# guide4 절 제목 색인 (자동 생성 — scripts/split-guide.cjs)

과목 경계(파일)는 Chapter 헤더가 처음 나오는 PDF 페이지 시작 기준. 절 코드 패턴: `^\s*\d\.\d+\.(\d+\.)?\s+\S` (예: ` 2.1.1. 화장품 원료의 종류`).

같은 코드가 여러 번 나오는 이유: 원문 각 페이지 상단에 그 페이지가 속한 절(2~3단계 코드) 제목이 반복 헤더로 인쇄되어 있어, 같은 코드가 그 절이 걸쳐 있는 페이지 수만큼 반복 등장한다. 아래 표는 발견된 모든 줄을 그대로 실었고(요약·중복 제거하지 않음), `구분` 열이 `목차`인 것은 s0_front.txt(머리말·목차 영역), `본문`인 것은 s1~s4.txt(실제 본문) 안에서 발견된 것이다.

4개 과목 파일(s1~s4) 모두에서 절 제목 패턴이 잡혔다(아래 표·요약 참고).
