## 참고/주의사항 (자세히 읽어야 하는 항목)

1. **안전기준규정_별표3_알레르기.txt는 작성하지 않았다.** 브리프는 "있으면"이라고 조건부로 요청했는데, 실제 「화장품 안전기준 등에 관한 규정」의 별표 3은 "인체 세포·조직 배양액 안전기준"이며 알레르기 유발성분과 무관하다. 알레르기 유발성분 25종은 대상 5(알레르기표시규정_별표2)에 정확히 있다. 안전기준규정의 실제 별표3(인체세포·조직배양액)은 이번 수집 범위에 없다(원문 PDF 안 `안전기준규정_전문.txt`에는 있으나 브리프 요구 파일명이 아니어서 최종본에 옮기지 않음 — 필요하면 재요청).

2. **화장품법시행규칙 별표1·2·6·9 및 서식류는 수집하지 않았다.** 브리프가 요구한 것은 별표 3·4·5·7뿐이라 그것만 받았다.

3. **기능성화장품 심사에 관한 규정 별표4(고시원료함량) 파일은 pdftotext -layout의 2단 레이아웃 특성상 왼쪽 열과 오른쪽 열이 같은 줄에 섞여 나온다.** 예: "1 닥나무추출물 2%" 옆에 다른 표의 "26 폴리실리콘-15..." 이 같은 줄에 붙어 나오는 식. 원문 그대로 보존 원칙에 따라 임의로 재배열하지 않았다. 문항 작성 시 이 파일만으로 표를 판단하지 말고, 헷갈리는 항목은 반드시 `sources/law/기능성심사규정_별표4_고시원료함량.txt`의 문맥과 함께 원본 PDF(law.go.kr 첨부파일, flSeq=160447641)를 다시 확인할 것.

4. **개인정보보호법.txt는 두 버전이 한 화면에 섞여 있는 law.go.kr 표준 표기를 그대로 저장한 것이다.** 오늘(2026-09-05) 기준 현행법은 법률 제20897호(2025-10-02 시행)이지만, 시험일(2026-09-19) 기준으로는 법률 제21445호(2026-03-10 공포, 2026-09-11 시행)가 이미 적용된다. law.go.kr의 본문 화면은 이미 개정된 조문 내용(예: 제23조·제24조·제29조·제31조 등)을 표시하면서 각 조문 끝에 `[시행일: 2026. 9. 11.]`라는 각주를 붙이는 방식으로 "곧 시행될 조문"을 미리 보여준다. 즉 본문에 있는 문구 자체는 이미 exam 시점 기준 유효한 내용이고, 각주는 "그 조문이 언제부터 유효한지"를 알려주는 것뿐이다. 별도의 21445호 전용 페이지(lsiSeq)는 찾지 못했다(efYd=20260911 파라미터를 시도했으나 20251002로 되돌아감). 부칙 본문에서도 법률 제21445호 자체의 부칙(경과조치)은 확인하지 못했다 — 필요하면 재조사 필요.

5. **표시광고실증규정.txt에는 "제출 기한" 조문이 없다.** 이 고시(제1~6조) 자체는 실증자료의 요건만 규정하고, 제출 기한(요청받은 날부터 15일 이내)은 상위법인 화장품법 제14조제3항에 있다. 파일 첫 줄에 이 사실을 적어두었다.

6. **CGMP.txt 헤더의 고시번호 불일치**: law.go.kr 제목줄은 "식품의약품안전처고시 제2024-46호"라고 표시하지만 본문 마지막 부칙은 "<제2024-26호, 2024. 8. 22.>"로 되어 있다(둘 다 시행일은 2026(원문 그대로: 2024). 8. 22.로 동일). law.go.kr 원문 자체의 표기 불일치이며 임의로 고치지 않고 그대로 옮겼다.

7. **화장품법시행령 별표1·2의 "시행일"은 시행령 전체 시행일(2026-04-02, 원 고시는 2026-03-10 개정)과 다를 수 있다.** 각 별표 자체의 마지막 개정일을 파일 헤더에 병기했다(별표1은 2019-12-10 개정 유지, 별표2는 확인 필요 — 헤더에 정확한 개정일을 못 박지 못한 부분은 파일을 열어 재확인할 것).

## 자기 검토

- 22개 파일 모두 첫 줄에 `# {법령명} — 시행 {날짜} — {번호} — 출처 URL — 수집 2026-09-05` 형식의 헤더가 있다. "시행 확인 실패"로 표기한 파일은 없다(모든 대상에서 law.go.kr 화면 상단에 시행일이 명시되어 있었다).
- 본문 내용은 브라우저 `text` 출력 또는 `pdftotext -layout` 출력을 그대로 저장했다(요약·수정 없음). law.go.kr 페이지의 좌측 메뉴·공유버튼 등 순수 UI 텍스트("카카오톡", "저장", "닫기" 등)만 잘라냈고 조문 텍스트는 손대지 않았다.
- 근거 없이 추측으로 채운 조문은 없다. 확인이 안 되거나 브리프 범위 밖인 항목(안전기준규정 별표3-알레르기, 화장품법시행규칙 별표1·2·6·9, 개인정보보호법 21445호 전용 부칙)은 파일을 만들지 않고 위 "참고/주의사항"에 실패·미수집으로 기록했다.
- git 커밋/add/stash는 실행하지 않았다.
